# Wortschatz Daily

Independent list-first German Vocabulary PWA (not the original `wortschatz`).

## Live site

After enabling GitHub Pages (Settings → Pages → **Deploy from a branch** → **main** → **/(root)** → Save):

https://robinmarks45-eng.github.io/wortschatz-daily/

## Features

- 60 Day 1 words, 25 active and 35 passive
- Sticky German word column with horizontal scroll for forms, Myanmar meaning and example
- Compact/Full views, filtering and search
- Word Detail Reader with Back/Next, German text-to-speech, notes
- Local IndexedDB progress, review list, resume position
- JSON lesson import with duplicate checking and manual backup/restore
- Offline support via service worker after first successful online visit

## Important

Learning progress is stored locally in the particular browser/PWA installation; it **does not sync** across devices. Export backups regularly. No OpenAI API key or remote tracking.

For iPhone Safari, open the live site → Share → Add to Home Screen. Existing original app remains unchanged.
